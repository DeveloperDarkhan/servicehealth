# Go Health Check - Проверка состояния сервисов

Это пример реализации инструмента для проверки состояния веб-сервисов на языке Go.

## Возможности

✅ **Проверка HTTP статуса** - Проверяет, что сервис возвращает статус 200  
✅ **Поиск ключевых слов** - Ищет заданное ключевое слово в теле ответа  
✅ **Автоматическая диагностика** - При сбоях автоматически запускает диагностику  
✅ **Подробное логирование** - Записывает все операции в лог файл  
✅ **Базовая диагностика** - DNS, порты, SSL, задержка  
✅ **Полная диагностика** - IP адреса, HTTP тайминги, заголовки  

## Установка и запуск

1. Убедитесь, что Go установлен на вашей системе
2. Перейдите в папку проекта:
   ```bash
   cd go-healthcheck
   ```
3. Инициализируйте модуль (если еще не сделано):
   ```bash
   go mod init go-healthcheck
   ```
4. Запустите проверку:
   ```bash
   go run cmd/healthcheck/main.go -url https://example.com/health
   ```

## Использование

### Базовая проверка
```bash
go run cmd/healthcheck/main.go -url https://httpbin.org/status/200
```

### Проверка с ключевым словом
```bash
go run cmd/healthcheck/main.go -url https://httpbin.org/json -keyword "origin"
```

### Полная диагностика
```bash
go run cmd/healthcheck/main.go -url https://httpbin.org/delay/2 -full-diagnostics
```

### Настройка таймаута
```bash
go run cmd/healthcheck/main.go -url https://httpbin.org/delay/5 -timeout 10s
```

## Параметры командной строки

| Параметр | Описание | По умолчанию |
|----------|----------|-------------|
| `-url` | URL для проверки (обязательный) | - |
| `-keyword` | Ключевое слово для поиска | "Success" |
| `-timeout` | Таймаут HTTP запроса | 10s |
| `-log-file` | Файл для логирования | "diagnostics.log" |
| `-full-diagnostics` | Включить полную диагностику | false |
| `-help` | Показать справку | false |

## Диагностические проверки

### Базовая диагностика (всегда выполняется):
1. **DNS разрешение** - Проверяет, что доменное имя корректно разрешается
2. **Проверка порта 443** - Проверяет доступность HTTPS порта
3. **SSL сертификат** - Проверяет действительность SSL сертификата
4. **Измерение задержки** - Измеряет время соединения

### Полная диагностика (с флагом `-full-diagnostics`):
5. **Локальный IP** - Получает локальный IP адрес
6. **Публичный IP** - Получает публичный IP адрес
7. **HTTP тайминги** - Анализирует время выполнения HTTP запросов
8. **HTTP заголовки** - Проверяет наличие важных заголовков безопасности

## Формат логирования

Все операции записываются в лог файл в формате:
```
[YYYY-MM-DD HH:MM:SS] [LEVEL] [ACTION] - Message
```

Пример лога:
```
[2024-01-15 10:30:45] [INFO] [HTTP_CHECK] - Код состояния 200 и тело ответа содержит ключевое слово "Success"
[2024-01-15 10:30:46] [INFO] [DNS_CHECK] - DNS разрешение для httpbin.org: 54.91.118.50, 3.208.97.215
[2024-01-15 10:30:47] [INFO] [PORT_CHECK] - Порт 443 доступен для httpbin.org
[2024-01-15 10:30:48] [INFO] [SSL_CHECK] - SSL сертификат действителен (истекает через 89 дней)
```
